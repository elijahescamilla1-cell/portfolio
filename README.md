# Portfolio — Elijah Escamilla

A Vite + React + TypeScript portfolio with a screenshot-driven case-study
`/work` page. Styled with a time-of-day theme (CSS variables), `Chakra Petch`
headings, mono labels, and `motion` scroll reveals.

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build
```

## Structure

```
src/
├── App.tsx              # Router (Home + Work)
├── components/          # Nav, Footer
├── pages/               # Home.tsx, Work.tsx
├── assets/work/         # 14 product screenshots used by Work.tsx
└── index.css            # Theme variables + Tailwind
```
